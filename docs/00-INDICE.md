## Datos actuales del proyecto

- Java 21
- Spring Boot 3.5.7
- Maven Wrapper 3.10.1
- Spring Data JPA / Hibernate
- Spring Security
- CSRF con cookie `XSRF-TOKEN` para sesiones
- Spring Validation
- Microsoft SQL Server
- HTML, CSS y JavaScript
- Chart.js
- SweetAlert2
- Swagger/OpenAPI

- Aplicación: `http://localhost:8087`
- Swagger: `http://localhost:8087/swagger-ui.html`
